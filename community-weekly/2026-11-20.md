## 本周头条

**1. Tecorigin GPU 支持合入，异构算力版图再下一城** @lipengfei-xh 在 HAMi 主仓合入 Tecorigin GPU 支持：核心/显存切分、指定卡与独占模式一应俱全；官网中英文用户指南、示例与排障文档同步上线。HAMi 支持的加速器家族再添一员。指南：https://project-hami.io/docs/userguide/tecorigin-device/enable-tecorigin-sharing

**2. volcano-vgpu-device-plugin v1.13.0 发布：无卡测试与签名镜像** 11 月 16 日发布 [v1.13.0](https://github.com/Project-HAMi/volcano-vgpu-device-plugin/releases/tag/v1.13.0)：新增 nvml-mock 支持——没有物理 GPU 也能跑设备插件测试；Helm chart 支持 runtimeClassName 与可配置的 ConfigMap 命名空间；设备健康状态跨重连保持；发布镜像全部采用 keyless cosign 签名；修复多条依赖 CVE。官网教程 lab 5 同步改用已发布的 nvml-mock 与 HAMi chart（@giuliocalzo），"无卡开发"闭环成型。

**3. AMD 生态三线并进：v0.5.0、无 CU Mask 共享与监控补齐** @moezdil 本周 31 个 PR 覆盖六个仓库：amd-device-plugin 合入无需 HSA_CU_MASK 的计算共享模式（0 CU 份额即可跑满全部 CU），并让业务容器复用 init 容器释放的 CU；amd-dra-driver 发布 v0.5.0；@Eshiv-Pandey 为 monitor 补上调度器分配的 AMD 显存上限上报。AMD 共享调度链路（device-plugin / DRA / 监控）全面补齐。

**4. HAMi-core CUDA Graph 显存管控系列合入** @maverick-woo（yuming.wu）以约百次提交完成 CUDA Graph 场景下 vGPU 显存配额的正确性系列：graph 执行前强制配额校验、保留 graph 池与输出生命周期记账、stream capture 结束前持续记账、graph 分配先于原生变更准入、per-thread stream 保持。同时将 GPU 共享基准结果写入 v2.10.0 官网文档。vGPU 显存隔离在 CUDA Graph 训练/推理负载下不再失守。

**5. HAMi-WebUI 大版本升级：物理加速器盘点与监控** @Nimbus318 以 13 个 PR 完成迄今最大一轮 WebUI 升级：物理加速器清单与指标面板、按精确 ID 匹配设备分配（节点重建不再残留陈旧记录）、MetaX C500 概览、Hygon HCU 升级兼容、NVIDIA MIG 显存统计修复，以及 About / 环境信息面板。

## 版本发布

- **volcano-vgpu-device-plugin v1.13.0**（11-16）：nvml-mock 无卡测试、Helm runtimeClassName、cosign 签名镜像、多条 CVE 修复。
- **amd-dra-driver v0.5.0**（11-17）：无 CU mask 计算共享等 AMD DRA 能力更新。

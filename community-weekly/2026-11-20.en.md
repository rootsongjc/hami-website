# HAMi Community Weekly · Issue #2

**2026-11-13 ～ 2026-11-20** ｜ For HAMi community users, enthusiasts and contributors ｜ Only what was completed this week

> **TL;DR**: Tecorigin GPU support landed in the main repo, volcano-vgpu-device-plugin v1.13.0 and amd-dra-driver v0.5.0 shipped, and ~100 commits brought CUDA Graph memory-quota enforcement to HAMi-core — 343 commits from 32 contributors this week, with the main repo at 5,037 stars.

---

## Top Stories

**1. Tecorigin GPU support merged — another accelerator joins the family** @lipengfei-xh landed Tecorigin GPU support in the main HAMi repo: core/memory splitting, card selection and exclusive mode included, with bilingual user guide, examples and troubleshooting docs published on the website. Guide: https://project-hami.io/docs/userguide/tecorigin-device/enable-tecorigin-sharing

**2. volcano-vgpu-device-plugin v1.13.0: GPU-less testing and signed images** Released Nov 16, [v1.13.0](https://github.com/Project-HAMi/volcano-vgpu-device-plugin/releases/tag/v1.13.0) adds nvml-mock support — you can now test the device plugin without any physical GPU. The Helm chart gains runtimeClassName and a configurable ConfigMap namespace; device health state survives stream reconnections; release images are all keyless-cosign signed; multiple dependency CVEs were fixed. Website tutorial Lab 5 was updated to use the published nvml-mock and HAMi charts (@giuliocalzo), completing the "no-GPU development" loop.

**3. AMD ecosystem advances on three fronts: v0.5.0, mask-free compute sharing, and monitoring** @moezdil merged 31 PRs across six repos this week: amd-device-plugin gained a compute sharing mode that needs no HSA_CU_MASK (a zero-CU share can use all CUs), and app containers can now reuse CUs released by init containers; amd-dra-driver shipped v0.5.0; @Eshiv-Pandey made the monitor report scheduler-assigned AMD memory limits. The AMD sharing stack (device plugin / DRA / monitoring) is now complete.

**4. CUDA Graph memory-quota control lands in HAMi-core** @maverick-woo (yuming.wu) completed a correctness series for vGPU memory quotas under CUDA Graph workloads in ~100 commits: enforce the quota before graph execution, account for retained graph pools and output lifetimes, keep stream-capture accounting until capture ends, admit graph allocations before native mutation, and preserve per-thread streams. He also added GPU sharing benchmark results to the v2.10.0 website docs. vGPU memory isolation now holds under CUDA Graph training/inference.

**5. HAMi-WebUI major upgrade: physical accelerator inventory and metrics** @Nimbus318 shipped the largest WebUI upgrade to date in 13 PRs: a physical accelerator inventory with metrics, device allocations matched by exact ID (no stale records after node recreation), MetaX C500 overview, Hygon HCU upgrade compatibility, NVIDIA MIG memory reporting fix, and an About/environment panel.

## Releases

- **volcano-vgpu-device-plugin v1.13.0** (Nov 16): nvml-mock GPU-less testing, Helm runtimeClassName, cosign-signed images, several CVE fixes.
- **amd-dra-driver v0.5.0** (Nov 17): mask-free compute sharing and other AMD DRA updates.

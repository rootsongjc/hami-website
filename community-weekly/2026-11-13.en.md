# HAMi Community Weekly · Issue #1

**2026-11-06 ~ 2026-11-13** | For HAMi community users, enthusiasts and contributors | Only what was completed this week

> **TL;DR**: HAMi v2.11.0 was officially released (220+ PRs, 50+ contributors, nine major features), and the community rode the momentum to land three more milestones — the new gpu-descheduler project made its open-source debut, HAMi joined the Vultr Open Source Alliance as a founding member, and KubeCon NA ContribFest was a success. GitHub Stars passed 5,000.

---

## Top Stories

**1. HAMi v2.11.0 officially released**
On November 4, HAMi v2.11.0 shipped: **220+ PRs merged, 50+ contributors, 29 first-time contributors**. Nine major features landed: Remote GPU (the Lupine remote passthrough solution), AMD Instinct memory sharing, Ascend ENPU dynamic partitioning, NUMA Refit topology rearrangement, Flexible MIG CDI support, OpenShift SELinux compatibility, a Helm Chart architecture refactor, and more. Within the week, the website wrapped up all release follow-ups: the full documentation archive in English and Chinese (~200 files), the Chinese changelog, v2.11.0 Prometheus alert rules with a new monitoring & alerting guide, the per-vendor feature support matrix in Get Started, and a rebuilt device support matrix with data fixes across three versions (v2.9 / v2.10 / Next).

**2. New project gpu-descheduler makes its open-source debut**
A new member of the HAMi ecosystem, [gpu-descheduler](https://github.com/Project-HAMi/gpu-descheduler), is now public: a **GPU defragmentation descheduler** for HAMi-virtualized clusters. Through a Mutating Admission Webhook and a Placement CRD, it consolidates vGPU workloads scattered across nodes to improve bin-packing density. Bilingual (EN/ZH) user guides went live on the website the same week (written by @tsingst).

**3. HAMi joins the Vultr Open Source Alliance as a founding member**
HAMi joined [the newly founded Vultr Open Source Alliance](https://project-hami.io/blog/hami-joins-vultr-open-source-alliance) as one of six founding members, alongside Spinifex, Upbound, Qdrant, Valkey and NetBird. Vultr previously provided the cloud GPU environment used to validate the HAMi v2.11.0 release. The announcement blog is out in both English and Chinese.

**4. KubeCon + CloudNativeCon North America 2026 ContribFest was a success**
On November 10 at the Salt Palace in Salt Lake City, the team hosted "GPU Virtualization: First Setup and Understanding the Device Plugin / DRA", an 80-minute hands-on lab led by Reza Jelveh, Mengxuan Li and Han Shen; the [slides](https://project-hami.io/resources/events/2026-kubecon-na/kubecon-na-2026-contribfest.pdf) are now on the website. All supporting demo material is ready and open source: hami-demo added the hamidemo CLI (A100 Flexible MIG and Remote CUDA demos), a vLLM-on-MI300X AMD sharing demo, and the inference-perf benchmark with TTFT/TPOT charts; hami-workshop shipped a general-purpose experiment environment upgraded to HAMi 2.11.0.

**5. GitHub Stars passed 5,000**
The main HAMi repository crossed 5,000 Stars this week (now 5,001). Ecosystem repos: HAMi-core 349 ★, volcano-vgpu-device-plugin 178 ★, HAMi-WebUI 96 ★, ascend-device-plugin 40 ★.
